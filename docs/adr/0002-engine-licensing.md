# ADR 0002. Шахматный движок и лицензия Stockfish

Статус: принято, 26.10.2026.

## Контекст
Для игры с компьютером, разбора партий и анти-чита нужен движок. Сильнейший открытый движок — Stockfish — под
лицензией GPL-3.0. Наше приложение закрытое.

## Что говорят мейнтейнеры Stockfish
- Stockfish можно вызывать как отдельную программу из программ с любой лицензией; линковать его можно только в
  GPL-программы.
- При распространении Stockfish нужно приложить текст лицензии и исходники (или точную ссылку на них), а
  пользователь должен видеть, что приложение содержит Stockfish.
- Обёртки для Flutter (`stockfish_chess_engine`, `dart-stockfish`) линкуют движок в процесс и сами под GPL-3.0.
- Прецедентов закрытых коммерческих приложений с Stockfish отдельным процессом, одобренных мейнтейнерами, не найдено.
- Сильного движка под MIT или Apache не найдено.

## Решение
1. **Уровни 1–5 — собственный движок** в `shared`: negamax, alpha-beta, iterative deepening, quiescence search,
   таблицы позиций фигур, transposition table. Сила около 1600–1800 на телефоне. «Человечность» через выбор из
   нескольких лучших ходов и заданную частоту ошибок. Работает офлайн, лицензионных обязательств нет.
2. **Верхние уровни, разбор партий и анти-чит — Stockfish на сервере** (модуль `engine-worker`, пул процессов,
   протокол UCI). Использование по сети не является распространением в смысле GPL-3.0 (это не AGPL), поэтому
   раскрывать код сервера не нужно.
3. Встраивать Stockfish в клиент не будем. Если это понадобится для офлайна, то только отдельным процессом через
   UCI, с маленькой сетью NNUE (около 6 МБ), экраном лицензий и ссылкой на исходники, и только после консультации
   юриста.

## Последствия
- APK остаётся маленьким: большая сеть NNUE Stockfish весит около 133 МБ.
- Верхние уровни бота требуют интернета.
- Серверный Stockfish переиспользуется для анти-чита и разбора партий в Premium.
