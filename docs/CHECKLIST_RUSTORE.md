# Чек-лист публикации в RuStore

Требования на 17.09.2026. Перед каждым релизом сверять с официальной документацией RuStore.

## 1. Аккаунт
- [ ] Регистрация через VK ID.
- [ ] Для бесплатного приложения достаточно физлица: регистрация мгновенная, без модерации.
- [ ] Для платежей (билеты, «Убрать рекламу», Premium): ИП или юрлицо. С 01.02.2026 платёжные SDK физлицам и
      самозанятым недоступны. ИП на НПД оформляется за 3–5 дней, перевод аккаунта — 1–2 рабочих дня.
- [ ] Усиленная квалифицированная электронная подпись (нужна ИП и юрлицу).

## 2. Сборка
- [ ] APK или AAB до 5 ГБ, `targetSdk` не ниже 28 (мы собираем с 36).
- [ ] 64-битные библиотеки, если есть нативный код.
- [ ] Подпись тем же ключом разработчика, что и в других сборках `rustore`.
- [ ] Flavor `rustore`: без ссылок на Google Play и другие магазины.
- [ ] Вход без сторонних ресурсов: e-mail, телефон или VK ID, а не только Google Sign-In.
- [ ] RuStore Push SDK (транспорты RuStore, FCM, HMS).
- [ ] RuStore Pay SDK для покупок (BillingClient SDK устарел, платежи через него прекращены с 01.08.2026).
- [ ] Серверные уведомления о платежах на наш бэкенд.
- [ ] Yandex Mobile Ads вместо AdMob.
- [ ] Yandex AppMetrica.

## 3. Требования к содержимому
- [ ] Все платёжные решения задекларированы в консоли.
- [ ] Цены показываются в рублях.
- [ ] Нет азартных игр с выводом денег: призы за турнирные билеты только виртуальные.
- [ ] Разрешения соответствуют функциональности (`INTERNET` не требует декларации).
- [ ] Согласие пользователя на обработку персональных данных.
- [ ] Статус оператора персональных данных: уведомление в Роскомнадзор подано, база россиян в России.

## 4. Карточка
- [ ] Название до 30 символов, краткое описание до 80, полное до 4000 (пользователю видно первые 2000).
- [ ] Иконка 512×512, до 3 МБ, PNG или JPG, залита на всю площадь без прозрачных краёв.
- [ ] Скриншоты: минимум 3 на тип устройства; телефон до 2160×3840 и 3 МБ, планшет до 1920×1080 и 5 МБ.
- [ ] Категория, возрастной рейтинг, минимум один контакт (e-mail, группа VK, сайт).
- [ ] Декларация о безопасности пользовательских данных.

## 5. Модерация
- [ ] Тестовый аккаунт (логин и пароль) в комментарии к сборке.
- [ ] Учесть сроки: обычно от нескольких часов до 3 рабочих дней, обновления быстрее.

## 6. Продвижение
- [ ] Заявка на фичеринг (критерии: установки, рейтинг, доход с платящего пользователя).
- [ ] Платное продвижение внутри RuStore: VK Ads (баннер «Интересное», поиск), модели CPM и CPI.
- [ ] Яндекс Директ: продвижение приложений из RuStore в единой перфоманс-кампании.
- [ ] Remote Config и Tracer из консоли RuStore.
- [ ] Ответы на отзывы.
